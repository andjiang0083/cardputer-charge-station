# 充电座（Charge Station）— 给 M5Stack Cardputer / Cardputer-Adv

**插上电，机器不会告诉你到底在不在充。这个固件就干一件事：用颜色告诉你。**

刷进去之后，Cardputer 变成一台充电座：灭屏、CPU 降到 80MHz、射频根本不启动，按键时给你一个判定——**橙黄 = 正在充**，绿 = 满了，红 = 接着但没电流，灰 = 没在充。

> 这块板子读不到充电状态寄存器，也没有电流计 —— 所以它读电池电压的趋势，靠斜率判断。

---

## 要解决的问题

Cardputer 没有充电指示灯，软件里也拿不到充电状态（`M5.Power.isCharging()` 返回 *unknown*）。屏幕一灭、壳一合，下面三种完全不同的情况长得一模一样：

- 好好地在充，
- 插在一个供不上电的口（Mac 的 USB 口、没供电的 hub、劣质线），
- 开关是 OFF —— 这时候**电池在物理上是断开的，无论充电头多强都充不进去**。

充电座把这三件事分开，并且把证据摆出来：一条带真实刻度的电压曲线。

## 屏幕上有什么

```
CHARGE STATION                     39m
4.02V          NO CHARGE
~87%           -1.74mV/m
-----------------------------------
No charge: switch/cable/port
[───── 40 分钟电压曲线 ─────]
```

| 颜色 | 状态 | 含义 |
|---|---|---|
| **橙黄** | `正在充` / `慢充中` | 电压在往上走，电真的进得去 |
| **绿** | `已充满` | 到 4.15V，可以拔了 |
| **红** | `供不上` | 接着，但电压不涨 —— 电源带不动 |
| **灰** | `没在充` | 电压在掉，没在充 |
| **红** | `无电池` | 开关 OFF（电池断开）或没装电池 |

还在充的时候会给出预计充满时间和估算的净充电电流（`~63mA`，由斜率反推）。

## ⚠️ 抱怨"充不进去"之前先看这三条

1. **开关必须拨到 ON。** OFF 是断电池，物理上就充不了，而且 ADC 读的是浮空引脚。这是最常见的"充不进电"原因。
2. **给它几分钟。** 判定靠电压斜率：第一次出结论要约 3 个采样（90 秒），可信的斜率要 10 分钟左右。
3. **不是每个口都行。** Mac 的 USB 口或没供电的 hub 供的电流可能不够整机消耗，你会看到 `供不上` 或 `没在充`，曲线往下掉 —— 那不是 app 坏了，是它把真相告诉你了。

## 安装

**推荐：作为 app 通过 M5Launcher 装**（保留你的 NVS、其他 app 和配置）：

- 编译/烧录 `firmware.bin` 到 `0x10000`，或用 M5Launcher 安装 `.bin`
- 过夜记录和语言选择都在本 app 自己的 NVS 命名空间里，切换 app 不会丢

**不推荐：整片合并镜像烧 `0x0`** —— 它会把 NVS 分区（语言选择、M5Launcher 配置、Wi-Fi 密码）整片写成 `0xFF`。

## 按键

| 按键 | 作用 |
|---|---|
| 任意键 | 亮屏 3 秒 |
| `R` | 常亮 5 分钟（到点自动灭） |
| `+` / `-` | 校准微调，±10mV 一档，范围 ±200mV（存盘） |
| `L` | 中英切换 |
| `1` / `2` | 直接选中文 / 英文 |
| `9` | 清空过夜记录 |
| `0` | 清掉语言选择并重启，回到选语言页 |

首次开机会问语言：`[1] 中文` / `[2] English`，60 秒不选**默认英文**。

## 过夜记录

每 10 分钟往 flash 写一条（电压 + 状态），144 条 = 24 小时，满了环形覆盖。插回电脑就能读：

```bash
python3 tools/read_log.py            # 按 MAC 自动找端口
python3 tools/read_log.py /dev/cu.usbmodem5
```

它会把整夜曲线、插电/收尾/满电三个时刻、平均斜率都打出来。当你想知道"这一夜到底怎么充的"而不只是"有没有充"时有用。

## 老实交代

- **它不会让充电变快。** 充电 IC 和限流电阻是硬件定死的，这个 app 只是把负载降到最低（灭屏、80MHz、不启射频），让充电器能给多少给多少。
- **电流是估算值**，由电压斜率和一条典型的锂电电压-电量曲线反推，只能给量级，不是库仑计。
- **判定需要斜率**，所以刚插上的一两分钟显示"采集中"，这是诚实，不是坏了。
- 电压是从 GPIO10 经 1:2 分压读的，绝对精度差几十 mV，所以给了 `+` / `-` 校准。

## 编译

```bash
pio run -e cardputer
# app-only 镜像:  .pio/build/cardputer/firmware.bin        （烧 0x10000）
# 合并镜像:       .pio/build/cardputer/firmware.factory.bin （烧 0x0，会清 NVS）
```

PlatformIO + Arduino（M5Unified / M5Cardputer）。目标：`esp32-s3`、8MB flash、无 PSRAM。Flash 约 24%，RAM 约 9%。
